# RAG知识库清洗工具功能重构

## 问题分析

1. **项目符号丢失问题**：当前PDF提取函数虽然包含了对`[•●○]`等项目符号的匹配，但可能还有其他类型的项目符号未被捕获，导致提取时丢失。

2. **功能需求**：
   - 保留100%干净的原文（去除页眉页脚和无意义内容）
   - 直接提供保存为TXT格式的选项
   - 新增AI分析文档层级结构功能，返回JSON映射表
   - 根据JSON映射表生成带MD格式的版本

## 实现计划

### 1. 修复PDF提取函数

- **增强项目符号识别**：扩展正则表达式，支持更多类型的项目符号（如■、□、△、▴、▾等）
- **优化提取逻辑**：确保所有可见的项目符号都能被正确保留
- **保持物理提取的纯净性**：不做任何内容修改，只去除页眉页脚和无意义内容

### 2. 新增AI层级分析功能

- **创建新函数**：`analyze_document_structure`
- **功能**：将干净的原文喂给AI，让AI分析文档的层级结构
- **返回格式**：JSON映射表，例如：`{"第一章": "#", "一、": "##", "（一）": "###", "1.": "保持原样"}`
- **进度反馈**：添加进度条，显示AI分析进度

### 3. 实现MD格式转换功能

- **创建新函数**：`apply_md_formatting`
- **功能**：根据AI生成的JSON映射表，为原文添加适当的Markdown标签
- **保持原文完整性**：不修改原文内容，只在行首添加#、##等Markdown标签
- **支持保存选项**：提供保存为TXT或MD格式的选项

### 4. 优化用户界面

- **更新侧边栏**：添加新的功能选项
- **流程优化**：
  1. 上传文件 → 显示干净的原文 → 可直接保存为TXT
  2. 点击"分析层级结构" → AI生成JSON映射表
  3. 点击"应用MD格式" → 生成带MD格式的版本 → 可保存为TXT或MD
- **进度和状态反馈**：为每个步骤添加清晰的状态提示

### 5. 代码结构调整

- **模块化**：将功能拆分为独立的函数，提高代码可维护性
- **错误处理**：增强错误处理，确保在API调用失败时能给出清晰的错误信息
- **性能优化**：确保物理提取过程快速响应

## 预期效果

- **物理提取**：快速、准确地提取PDF内容，保留所有项目符号和格式
- **AI分析**：智能识别文档层级结构，生成准确的JSON映射表
- **MD转换**：根据映射表生成格式规范的Markdown文档
- **用户体验**：流程清晰，反馈及时，操作简单

## 技术要点

- 使用pdfplumber进行高精度PDF提取
- 利用OpenAI API进行文档结构分析
- 实现基于规则的Markdown格式转换
- 优化Streamlit界面，提供流畅的用户体验
