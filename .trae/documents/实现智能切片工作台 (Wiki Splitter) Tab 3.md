# 智能切片工作台 (Wiki Splitter) 实现计划

## 核心功能实现

### 1. 数据输入区
- 添加新的 Tab 3 到现有应用
- 实现两种数据来源方式：
  - 联动模式：读取 Tab 2 保存在 st.session_state 中的 Markdown 文本
  - 独立模式：通过 st.file_uploader 上传本地 .md 文件

### 2. 左侧栏：可视化树状控制台
- **文档树解析**：使用正则表达式 `^#+\s+(.*)` 解析 Markdown 文本，提取所有标题及其层级
- **树状结构构建**：在内存中构建文档树，记录每个标题的层级、内容和位置
- **UI 树状渲染**：
  - 使用 st.checkbox 渲染树状结构
  - 根据标题层级计算缩进，使用特殊字符（如 ┣━、┗━）模拟层级关系
  - 实现父子吞并原则的 UI 逻辑

### 3. 右侧栏：实时预览与元数据配置
- 提供母目录名称输入框
- 实时预览根据用户勾选状态生成的原子文件列表
- 文件名处理：过滤操作系统非法字符和开头的 # 号

### 4. 执行与导出区
- 实现【生成并打包 ZIP】按钮
- 执行逻辑：
  - 遍历原始文本，根据勾选的标题节点截取对应的文本块
  - 注入极简 YAML 元数据
  - 生成 00_总路由.md 文件
  - 打包所有文件为 ZIP 并提供下载

## 技术实现要点

### 父子吞并原则实现
- 当父节点被勾选时，自动将其所有子节点视为已勾选（逻辑上包含）
- 当子节点被勾选时，确保其父节点不被勾选，避免冲突
- 在 UI 上添加提示信息，说明父节点勾选后子内容会自动打包

### UI 树状渲染实现
- 使用正则表达式解析 Markdown 标题，提取层级和内容
- 根据标题层级计算缩进级别
- 使用特殊字符（如 ┣━、┗━）和空格组合，视觉上模拟树状结构
- 为每个标题生成唯一的复选框 key，确保状态管理正确

### 健壮性保障
- 严格使用 utf-8 编码处理文本
- 文件名生成时过滤所有操作系统非法字符（\/:*?"<>|）
- 处理边界情况，如空文本、无标题等
- 添加错误处理和用户提示

## 代码结构
- 在现有 streamlit_app.py 文件中添加 Tab 3 相关代码
- 新增必要的辅助函数，如标题解析、树状结构构建、ZIP 打包等
- 保持代码风格与现有应用一致
